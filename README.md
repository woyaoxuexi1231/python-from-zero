# Python 从零开始

Python 入门教程：后端练习代码 + 前端课程笔记。

## 目录结构

```text
python-from-zero/
├── backend/     # Python 练习代码（36 课）
└── frontend/    # Vue 课程笔记站点
```

## 后端：跑练习

```powershell
cd backend
python 01_hello/01_hello.py
```

详细说明见 [backend/README.md](backend/README.md)。

## 前端：读笔记

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:13001/> ，按章节阅读 36 课笔记。
