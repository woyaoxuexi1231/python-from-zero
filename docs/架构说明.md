# 植恩智能客服 — 仓库说明

## 你在做什么

已有 **DeepSeek R1（Ollama）**。现在补 **RAG 层**：客服请求先进 Python 服务，检索知识后再调大模型。

```
用户 / 客服前端
       │
       ▼
  rag-service   ←── 部署到服务器的智能客服 RAG 服务
       │
       ├──► Milvus（只读检索）
       └──► DeepSeek R1 / Ollama（生成回答）
```

**切片、导入数据** 由离线工具 `rag-ingest` 完成；知识库 TXT 放在仓库根 `knowledge/`（与 `rag-ingest` 同级）。

```
knowledge/*.txt  ──►  rag-ingest（切片 + 嵌入 + 写入）  ──►  Milvus
```

## 目录

| 路径 | 是什么 | 部署？ |
|------|--------|--------|
| `rag-service/` | 智能客服 RAG HTTP 服务（FastAPI） | **是**，上服务器 |
| `rag-ingest/` | 知识库导入 CLI | **否**，运维/本地用 |
| `knowledge/` | 知识库 TXT（ingest 输入） | 否 |
| `文档/` | 客户原始资料与样例 JSON | 否 |
| `docs/` | 运维与架构文档 | 否 |
| `docker-compose.milvus.yml` | 本地/测试起 Milvus | 基础设施 |

## 推荐顺序

1. 起 Milvus：`docker compose -f docker-compose.milvus.yml up -d`  
2. 导入知识：进入 `rag-ingest`，`uv sync` → `uv run python -m app --build`  
3. 起客服服务：见 `rag-service/README.md`  
4. 调 `POST /v1/chat`  

更细的 Milvus / Ollama 排障见 `docs/RAG_MILVUS教程.md`。
