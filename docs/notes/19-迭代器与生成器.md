# 第 19 课：迭代器与生成器

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：iter/next/StopIteration、迭代器一次性、yield 惰性、生成器表达式。

---

你一直在写 `for x in ...`。背后机制是：先 `iter` 拿迭代器，再反复 `next`。生成器用 `yield` 写出「按需现算」的迭代器—— 数据大或要无限序列时，这是关键。

## 可迭代 vs 迭代器

列表、字符串、字典、range 都是可迭代对象。for 对它们做两件事：

```python
nums = [10, 20, 30]
it = iter(nums)
print(next(it))  # 10
print(next(it))  # 20
print(next(it))  # 30
# 再 next → StopIteration
```

> **原理**
>
> 迭代器记住位置，取一个往前走一步，不能回头。 列表可以反复 for；同一个迭代器用 `list(it)` 第二次往往是空的。

## 自己写迭代器类

```python
class Countdown:
    def __init__(self, n: int) -> None:
        self.current = n

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value

for x in Countdown(3):
    print(x)  # 3 2 1
```

## 生成器：yield 更省事

```python
def countdown(n: int):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)
```

函数体遇到 `yield` 就暂停交出值；下次再从断点继续。 返回的是生成器对象，不会一次算完所有结果。

> **踩坑**
>
> 生成器也是一次性的。要再遍历，重新调用生成器函数。 无限序列（如不断 yield 下一个数）不要 `list()` 收——会挂住。

## 生成器表达式

```python
# 列表推导：立刻算完进内存
squares = [x * x for x in range(5)]
# 生成器表达式：惰性
squares_g = (x * x for x in range(5))
```
