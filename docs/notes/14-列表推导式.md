# 第 14 课：列表推导式

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：映射与过滤的短写法、与 for+append 对照、何时不该用推导式。

---

第 4 课会用 for 往空列表里 append。 推导式把「建空列表 → 循环 → append」压成一行。 先会 for，再压缩；看不懂就拆回 for。

## 先写你会的 for

```python
nums = [1, 2, 3, 4]
doubled = []
for n in nums:
    doubled.append(n * 2)
# [2, 4, 6, 8]
```

## 同一件事，写成推导式

```python
doubled = [n * 2 for n in nums]
```

读法：对可迭代里的每一项，算左边的表达式，放进新列表。

## 加 if：只要符合条件的

```python
positives = [n for n in [-2, 0, 3, 5] if n > 0]
# [3, 5]
```

> **原理**
>
> 句式是 `[表达式 for 变量 in ... if 条件]`。 条件写在最后；不符合的直接跳过，不会进新列表。

## 映射 + 过滤可以一起

```python
scores = {"小明": 90, "hulei": 75, "小红": 40}
passed = [name for name, score in scores.items() if score >= 60]
labels = [f"{score} 分" for score in scores.values()]
```

## 什么时候别用

- 循环体步骤多、要打印、要改外部状态 → 老实写 for
- 嵌套两层以上的推导式 → 新手先别写，可读性差

集合、字典也有推导：`{...}` / `{k: v for ...}`。练习优先用列表 `[]`。

> **踩坑**
>
> 推导式不是越短越好。同事读不懂的一行，不如三行 for。 Python 社区更偏向「清晰的推导式」，不是「炫技的一行」。
