# 第 23 课：装饰器

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：函数一等公民、手写包装、@ 语法糖、*args/**kwargs、functools.wraps。

---

想在多个函数前后打日志、计时、校验，又不想复制粘贴？ 装饰器就是「包一层」的语法糖：`@deco` 等价于 `func = deco(func)`。

## 铺垫：函数是一等公民

```python
def greet(name: str) -> str:
    return f"你好，{name}"

def apply(f, v):
    return f(v)

print(apply(greet, "小明"))
```

## 手写包装器

```python
def log_deco(func):
    def inner(name):
        print(f"[日志] 准备调用 {func.__name__}")
        result = func(name)
        print(f"[日志] 结束，结果={result!r}")
        return result
    return inner

def greet2(name: str) -> str:
    return f"你好，{name}"

wrapped = log_deco(greet2)
print(wrapped("小红"))
```

## @ 语法糖

```python
@log_deco
def greet3(name: str) -> str:
    return f"你好，{name}"

print(greet3("hulei"))
```

> **原理**
>
> 装饰器接收函数，返回新函数。调用新函数时：先做额外事，再调原函数，再返回结果。 原函数定义本身没被改写，只是名字指向了包装后的版本。

## *args / **kwargs 透传

```python
def timed(func):
    def inner(*args, **kwargs):
        # ... 计时
        return func(*args, **kwargs)
    return inner
```

包装器不要写死参数形态，才能套在任意函数上。

## functools.wraps

```python
import functools

def deco(func):
    @functools.wraps(func)
    def inner(*args, **kwargs):
        return func(*args, **kwargs)
    return inner
```

> **踩坑**
>
> 不加 wraps，`__name__`/`__doc__` 会变成 inner，调试和文档都错乱。 带参装饰器是「三层」：外层收参数，中层收 func，内层才是调用时跑的——先会无参再学带参。
