# 第 4 课：列表与循环

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：列表与索引、for 逐项处理、循环里判断、累计求和、append 收集结果。

---

单个变量装一个值；现实里常常要处理「一排」：一组成绩、一串名字。 这一课学两个搭档：**列表**存数据，**for 循环**逐项干活。

## 列表：有顺序的一排东西

方括号 `[]`，逗号分隔。类型标注 `list[int]` 表示「装满整数的列表」。

```python
ages: list[int] = [15, 18, 20, 12]
names: list[str] = ["小明", "hulei", "小红"]
print(names[0])    # 小明 —— 索引从 0 开始
print(len(names))  # 3
```

> **踩坑**
>
> 第一个元素是 `[0]`，不是 `[1]`。 访问超出长度会 `IndexError`。先用 `len` 心里有数。

## for：把每一项拿出来做一次

```python
for name in names:
    print(f"你好，{name}")
```

`name` 是你起的临时名字，每一轮绑定下一项。 循环里可以再套 if——「对每一项做判断」非常常见。

```python
for age in ages:
    if age >= 18:
        print(f"{age} 岁，成年")
    else:
        print(f"{age} 岁，未成年")
```

## 累计：先准备盒子，再往里加

求和、计数都是同一套路：初始化 → 循环更新 → return。

```python
def sum_demo(numbers: list[int]) -> int:
    result = 0
    for n in numbers:
        result = result + n
    return result

print(sum_demo([1, 2, 3, 4]))  # 10
```

> **原理**
>
> `result` 必须在循环外初始化。放进循环里会每圈清零； 不初始化则第一次 `result + n` 会 `NameError`。

## append：往末尾加一项

```python
nums: list[int] = [1, 2]
nums.append(3)
print(nums)  # [1, 2, 3]
```

之后做「过滤出合格的人」时，常是：空列表 + 循环 + 条件满足则 append。
