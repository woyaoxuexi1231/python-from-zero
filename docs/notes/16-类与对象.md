# 第 16 课：类与对象

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：__init__ 与 self、方法绑数据、@property、__str__/__repr__、对象排序。

---

前面常用 dict 装数据，操作数据的函数另写。 **类**把数据（属性）和行为（方法）绑在一起——对象带着自己的能力走。

## 第一个类

```python
class Student:
    def __init__(self, name: str, score: int) -> None:
        self.name = name
        self.score = score

    def is_pass(self) -> bool:
        return self.score >= 60

    def __str__(self) -> str:
        return f"{self.name}: {self.score} 分"

s1 = Student("小明", 90)   # 不用 new
print(s1.name, s1.is_pass())
print(s1)
```

> **原理**
>
> `__init__` 是构造器，创建时自动调用。 `self` 是「这个对象自己」（类似 this）。 方法第一个参数必须是 self；调用时 `s1.is_pass()` 不用手动传。

## 和 dict 对比

dict 版要另写 `is_pass(d)`；class 版 `s.is_pass()` 顺着对象就能调。 行为跟着数据走，这就是 class 的价值。

## @property：算出来的属性

```python
class StudentV2:
    def __init__(self, name: str, score: int) -> None:
        self.name = name
        self.score = score

    @property
    def level(self) -> str:
        if self.score >= 90:
            return "优秀"
        if self.score >= 60:
            return "及格"
        return "不及格"

print(StudentV2("阿", 95).level)  # 像属性，不加括号
```

## 对象也能排序

```python
students = [Student("小明", 90), Student("hulei", 75), Student("小红", 40)]
by_score = sorted(students, key=lambda s: s.score, reverse=True)
```

> **踩坑**
>
> 列表里 print 对象要用 `__repr__`（或让它复用 `__str__`）， 否则看到的是内存地址。`print(s)` 走 `__str__`；容器调试常走 repr。
