# 第 6 课：成绩本——拼起来

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：数据 + 一事一职函数 + 主流程；None 表示找不到；平均分与及格名单。

---

前五课是零件；这一课把它们装成一台小机器——成绩本。 不教全新语法，练的是**怎么组织一个小程序**：数据、函数、主流程。

## 小程序通常长这样

2. 数据（这里是成绩字典）
4. 几个各干一件事的函数
6. 从输入到输出的主流程

```python
scores: dict[str, int] = {
    "小明": 90,
    "hulei": 75,
    "小红": 40,
}
```

## 函数：一事一职

```python
def add_score(book: dict[str, int], name: str, score: int) -> None:
    book[name] = score   # 有则改，无则加

def get_score(book: dict[str, int], name: str) -> int | None:
    if name in book:
        return book[name]
    return None

def letter(score: int) -> str:
    if score >= 90:
        return "优秀"
    elif score >= 60:
        return "及格"
    return "不及格"
```

> **原理**
>
> 找不到人时返回 `None`（「没有」），而不是瞎返回 0—— 因为 0 分可能是真实成绩。调用方用 `if score is None` 区分「没有」和「零分」。

## 展示与交互

```python
def print_report(book: dict[str, int]) -> None:
    print("----- 成绩单 -----")
    for name, score in book.items():
        print(f"{name}: {score} 分，{letter(score)}")

def lookup() -> None:
    name = input("要查询谁的分数？")
    score = get_score(scores, name)
    if score is None:
        print(f"没有 {name} 这个人")
    else:
        print(f"{name} 是 {score} 分，{letter(score)}")
```

## 汇总类函数

```python
def average_score(book: dict[str, int]) -> float:
    total = 0
    for score in book.values():
        total += score
    return total / len(book)

def passed_names(book: dict[str, int]) -> list[str]:
    names: list[str] = []
    for name, score in book.items():
        if score >= 60:
            names.append(name)
    return names
```

> **踩坑**
>
> 空字典时 `len(book)` 为 0，除法会 `ZeroDivisionError`。 入门可先假设成绩本非空；正式代码要先判空再除。

## 主流程：串起来跑一遍

```python
print_report(scores)
lookup()
# add_one()：input 姓名和分数，int 后 add_score
print_report(scores)
print(average_score(scores))
print(passed_names(scores))
```

现在程序是「直线」：跑完就结束。下一课用 while 做成能反复进菜单的交互。
