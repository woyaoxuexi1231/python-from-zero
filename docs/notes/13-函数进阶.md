# 第 13 课：函数进阶

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：默认参数、关键字参数、*args、多返回值复习、可变默认值陷阱。

---

第 1 课会写函数，第 10 课会 `return a, b`。 这一课让调用更省事：常不变的参数给默认值；个数不固定时用 `*args`。

## 默认参数：可以不传

```python
def greet(name: str, suffix: str = "同学") -> str:
    return f"{name}{suffix}"

print(greet("小明"))           # 小明同学
print(greet("小明", "老师"))   # 小明老师
```

> **踩坑**
>
> 有默认值的参数必须放在没有默认值的后面，否则 SyntaxError。

## 关键字参数：按名字传

```python
def letter(score: int, excellent: int = 90, passed: int = 60) -> str:
    if score >= excellent:
        return "优秀"
    elif score >= passed:
        return "及格"
    return "不及格"

print(letter(85, passed=80))  # 及格线改成 80
```

位置参数要写在关键字参数前面。

## *args：个数不固定

```python
def add_all(*nums: int) -> int:
    result = 0
    for n in nums:
        result += n
    return result

print(add_all(1, 2))
print(add_all(1, 2, 3, 4))
print(add_all(*[10, 20, 30]))  # 列表拆开传入
```

> **原理**
>
> 形参前加 `*`，函数里收到的是元组。 调用处对列表加 `*` 是「拆包传入」，和定义处的 `*` 是一对搭档。

## 默认值不要用空列表 / 空字典

```python
# 错误：def add_note(text, box=[]):  —— 多次调用会共用同一个列表
def add_note(text: str, box: list[str] | None = None) -> list[str]:
    if box is None:
        box = []
    box.append(text)
    return box
```

> **踩坑**
>
> 默认值在**定义函数时算一次**，不是每次调用新建。 可变对象作默认值会串数据。正确做法：默认 `None`，函数里再新建。
