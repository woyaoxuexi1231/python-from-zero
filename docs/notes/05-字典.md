---

列表靠编号找：`ages[0]`。很多时候你更想靠「名字」找： 「hulei 多少分？」——这就是字典：键 → 值。

## 字典：用键找值

花括号 `{}`，写成 `键: 值`。类型标注 `dict[str, int]` 表示键是字符串、值是整数。

```python
scores: dict[str, int] = {
    "小明": 90,
    "hulei": 75,
    "小红": 40,
}
print(scores["hulei"])  # 75
```

## 读、改、加

```python
print(scores["小明"])   # 读
scores["小明"] = 95     # 改
scores["小刚"] = 60     # 原来没有的键 → 新增
print(scores)
```

> **踩坑**
>
> 键不存在直接 `scores["xxx"]` 会 `KeyError`。 先用 `if "hulei" in scores:` 再取，或用后面课会再提的更稳妥写法。

## 循环字典

`for name in scores` 拿到的是键； `for name, score in scores.items()` 键值一起拿（拆包，第 10 课会正式讲）。

```python
for name, score in scores.items():
    if score >= 60:
        print(f"{name} 及格了，{score} 分")
    else:
        print(f"{name} 不及格，{score} 分")
```

> **原理**
>
> 字典的「成员判断」查的是键，不是值。 `"hulei" in scores` 为真；`75 in scores` 一般是假（除非有人叫 75）。

## 当函数的参数和返回值

```python
def get_score(book: dict[str, int], name: str) -> int:
    return book[name]

def total_score(book: dict[str, int]) -> int:
    result = 0
    for score in book.values():
        result += score
    return result
```

`.values()` 只遍历值；`.keys()` 只遍历键； `.items()` 两者都要时用。
