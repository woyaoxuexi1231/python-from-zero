## pathlib.Path：路径是对象

```python
from pathlib import Path

BASE = Path(__file__).resolve().parent
demo = BASE / "demo_data"
p = BASE / "20_files_paths.py"
print(p.name, p.stem, p.suffix, p.parent)
```

> **原理**
>
> 用 `/` 拼接，自动处理系统分隔符。别再字符串硬拼 `"a" + "/" + "b"`。Python 3.6+ 推荐 pathlib。

## 建目录、写文件、列一层

```python
demo.mkdir(exist_ok=True)
(demo / "note.tmp.txt").write_text("小明 90\n", encoding="utf-8")

for f in demo.iterdir():
    print(f.name)
```

## glob / rglob

```python
for f in demo.glob("*.txt"):
    print(f.name)          # 当前层匹配

for f in demo.rglob("*.txt"):
    print(f)               # 递归进子目录
```

> **踩坑**
>
> `iterdir`/`glob` 只看一层；要钻子目录用 `rglob`。 跑课文件时注意工作目录；用 `Path(__file__).parent` 定位最稳。

## 大文件：逐行读（可配生成器）

```python
def read_lines(path: Path):
    with path.open(encoding="utf-8") as f:
        for line in f:
            yield line.rstrip("\n")

for line in read_lines(demo / "note.tmp.txt"):
    print(line)
```

不要对巨型日志 `f.read()` 一次灌进内存；for line in f 本身就是惰性的。
