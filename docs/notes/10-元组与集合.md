# 第 10 课：元组与集合

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：不可变元组、拆包与多返回值、集合去重与 in、空集合必须用 set()。

---

成绩本已经能转圈、接错、存盘。这一课换两种容器，后面几乎每天都会碰到： **元组**（有序不可改）和 **集合**（去重、成员判断快）。

## 三种容器对照

- 列表 `list`：有序，可改，`[]`
- 元组 `tuple`：有序，不可改，`()`
- 集合 `set`：无序，不重复，`{1, 2}` 或 `set()`

> **踩坑**
>
> 空集合必须写 `set()`。写成 `{}` 得到的是空**字典**。 集合的 `{}` 里没有冒号；字典才是 `键: 值`。

## 元组：像列表，但不能改

```python
point: tuple[int, int] = (3, 5)
print(point[0])   # 3
# point[0] = 10   # TypeError
```

## 拆包：一次解开多个值

```python
x, y = point
print(x, y)   # 3 5
```

第 5 课其实用过：`for name, score in scores.items()`—— 每一轮就是一个 `(键, 值)` 元组在拆包。

## 函数返回多个值 = 返回一个元组

```python
def min_and_max(numbers: list[int]) -> tuple[int, int]:
    # ... 算出 smallest, largest
    return smallest, largest

low, high = min_and_max([8, 3, 15, 1])
print(low, high)   # 1 15
```

> **原理**
>
> `return a, b` 等价于 `return (a, b)`。 左边几个名字接住，就是拆包；也可以一个变量整包接：`pair = ...`。

## 集合：自动去重，in 很快

```python
tags: set[str] = {"python", "java", "python"}
print(tags)   # 只有两个，重复被丢掉；顺序不一定

print("python" in tags)   # True
tags.add("go")
tags.discard("java")
```

列表去重常写成 `list(set(xs))`（顺序可能变）；只要唯一性时直接用 set。
