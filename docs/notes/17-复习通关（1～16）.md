# 第 17 课：复习通关（1～16）

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门、复习

**摘要**：不教新语法：成绩场景串起函数、异常、推导、集合、None、class 等，配课自检。

---

这一课**不教新语法**。把第 1~16 课串成一个成绩管理场景， 每个小函数对应几课知识点——写得出来、对得上预期输出，才算真懂。

## 这一课在练什么

- 函数、默认参数、多返回值
- 字符串、类型转换、try/except
- 列表推导、过滤、sorted(key=)
- 集合去重与交集
- 切片、enumerate、None 判断
- class、property、对象排序

配课文件里函数骨架已写好，把 `pass` 换成实现，跑底部自检。

## 怎么刷复习课

2. 先读函数注释里的「要求」和「期望输出」，不要急着翻旧课文件。
4. 卡住再回到对应课号（注释里标了）。
6. 一题过一题；全绿再往下开第 18 课。

> **原理**
>
> 复习课的价值不是「再讲一遍」，而是**强制检索**： 隔几天还能不能从需求还原出写法。能还原，说明进长期记忆了。

> **踩坑**
>
> 常见翻车：0 分当「没有」、可变默认值、KeyError 不判断、 切片含尾、sorted 忘了 reverse、class 忘了 self。 自检失败时，对照报错类型回对应课，比盲改快。

## 建议你自己补的几件事

2. 把错题记成三行笔记：错在哪、正确写法、属于哪一课。
4. 离开答案，隔一天只凭注释再写一遍最难的两题。
6. 用自己的小数据改测试，确认不是「背输出」。

## 收束

第一阶段到此收束：从 print 到 class，你已经能搭交互小工具。 下一阶段从第 18 课开始：模块拆分、生成器、pathlib——代码开始「长大」。
