# 第 18 课：模块与包

**摘要**：import / from…import / as、模块互引、__name__ == "__main__"、单文件模块入门。

---

1~17 课代码都挤在一个文件里。现实要分文件、再拼回来。 这一课：`import`、`from…import`、`as`、`__name__`，以及自己写模块。

## 一个 .py 就是一个模块

同目录放 `tools.py`，里面有函数和变量； 另一个文件就可以借来用。文件夹 + `__init__.py` 才叫包——本课先用单文件模块。

## 三种引入方式

```python
import tools
print(tools.greet("小明"))
print(tools.PI)

from tools import square, greet
print(square(7))

import calc as c
print(c.mean([10, 20, 30]))
```

> **原理**
>
> `import 模块`：带前缀，不撞名，来源清晰。 `from…import`：短，但同名易撞。 `as`：改名避冲突或缩短长名。

## 模块之间也能互相 import

`calc.py` 可以 `from tools import add`，再对外提供 `sum_list`。 模块像积木，不是孤岛。

## __name__ == "__main__"

```python
# tools.py 末尾
if __name__ == "__main__":
    print("被直接运行了")
```

- 直接 `python tools.py` → `__name__` 是 `"__main__"`，演示代码会跑
- 被别人 import → `__name__` 是 `"tools"`，演示代码不跑

> **踩坑**
>
> 从第 18 课起每课一个文件夹。请在对应目录下运行主课文件， 或保证工作目录能找到同目录模块，否则 `ImportError`。
