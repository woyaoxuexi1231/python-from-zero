日志里抓日期、抓邮箱、抓手机号、把多余空格清干净——用字符串切片硬扣又慢又脆。 正则用一小段「模式」描述「长什么样」，一次搞定。这一课只讲最常用的四个函数和八个写法。

## 这一课解决什么问题

- 找第一个 → `re.search(...)`
- 全部匹配 → `re.findall(...)`
- 整段校验 → `re.fullmatch(...)`（输入校验优先用这个）
- 替换 → `re.sub(...)`

## 先记这八个写法

```text
\d   一个数字       \w   字母或数字       \s   空白
+    一个以上       *    零个以上         [..] 字符集合
(..) 分组           r"..." 字符串前加 r
```

## search / findall / fullmatch

```python
import re

re.search(r"\d+", "id=7 编号 2026").group()   # "7"（第一个）
re.findall(r"\d+", "id=7 编号 2026")          # ["7", "2026"]（全部）

# 校验必须整段：fullmatch（search 会漏判前后非法字符）
re.fullmatch(r"\d{11}", "13812345678")        # 匹配对象
re.fullmatch(r"\d{11}", "1381234567x")        # None（末尾多一个字母）
```

> **踩坑**
>
> **校验输入要用 `fullmatch` 而不是 `search`**。 `search` 只找中间一段，遇到 `"abc13812345678xyz"` 也以为合法。 `fullmatch` 要求从头到脚完全对上。

## 分组：取出不同段

```python
m = re.search(r"([a-z]+)(\d+)", "abc123")
m.group(1)   # "abc"
m.group(2)   # "123"

# findall 有分组时返回元组列表
re.findall(r"(\d{4})-(\d{2})", "2026-08 与 1999-12")  # [("2026","08"), ("1999","12")]
```

## 替换：sub

```python
re.sub(r"\d+", "#", "订单 7 号共 3 件")  # "订单 # 号共 # 件"
```

> **raw 字符串**
>
> 模式前加 `r`，如 `r"\d+"`，反斜杠按字面解释， 否则 `"\d"` 会被 Python 解析成转义。忘了 r 是最常见报错来源之一。
