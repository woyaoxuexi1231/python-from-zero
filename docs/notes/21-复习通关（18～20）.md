# 第 21 课：复习通关（18～20）

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门、复习

**摘要**：模块 + 生成器 + pathlib：扫目录统计 txt，汇总写 JSON。

---

不教新东西。用一个小项目把第 18~20 课串起来： 扫文件夹里所有 `.txt`，逐行统计行数与词数，再把汇总写成 JSON。

## 三课各自贡献什么

- **18 模块**：工具函数放 `course_tools.py`，主文件 import；注意 __name__
- **19 生成器**：yield 惰性逐行读，不一次读进内存
- **20 pathlib**：rglob 找文件、`/` 拼路径、写 JSON 存盘

## 典型骨架

```python
from pathlib import Path
import json
from course_tools import letter_grade, word_tokens

BASE = Path(__file__).resolve().parent

def read_nonempty(path: Path):
    with path.open(encoding="utf-8") as f:
        for line in f:
            if line.strip():
                yield line.rstrip("\n")
```

> **原理**
>
> 复习课考的是「拼装」：import 对不对、生成器是不是真 yield、 路径是否相对 __file__。自检失败时按题号回对应课。

> **踩坑**
>
> 在错误目录运行会导致 import 失败或找不到数据目录。 请进入 `21_review/` 再跑主文件。空行是否计入，严格按题目要求。
