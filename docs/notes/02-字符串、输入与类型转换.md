# 第 2 课：字符串、输入与类型转换

`Python 从零` · 更新于 2026-08-24 · 标签：Python、入门

**摘要**：字符串拼接、f-string、input 永远返回 str、int/float/str 显式转换、与函数联用的数据流。

---

第一课你学会了变量、类型和函数。真实程序里，数据往往来自**用户输入**或**文件**—— 而它们几乎总是以**字符串**的形式出现。 这一课解决三件事：怎么拼字符串、怎么读输入、怎么在「文本」和「数字」之间安全转换。

## 字符串拼接：`+` 的含义取决于类型

两个字符串可以用 `+` 拼在一起，这叫**拼接**，不是数学加法。 两个数字用 `+` 才是加法。同一个符号，操作数类型不同，行为就不同。

```python
first = "hu"
last = "lei"
full = first + last
print(full)   # hulei
```

变量里存的是字符串，`+` 就按字符串规则走。 变量里存的是整数，`+` 就按算术规则走。 第一课说的「类型决定你能做什么」，在这里第一次真正派上用场。

> **原理**
>
> Python 是强类型语言：`+` 不会偷偷把字符串和数字混算。 左边是 `str`、右边是 `int`，直接 `+` 会 `TypeError`—— 这是保护，不是刁难。

> **踩坑**
>
> `print("年龄是" + 18)` 会报错。 想输出「年龄是18」，要么把数字转成字符串：`"年龄是" + str(18)`， 要么用下面要说的 f-string。

## 显式转换：`str()`、`int()`、`float()`

类型不对时，不要指望 Python 猜你的意图——**自己转**。 三个最常用的转换函数：

- `str(x)`：任意值 → 字符串（拼进句子时用）
- `int(s)`：看起来像整数的字符串 → 整数（做加减乘除时用）
- `float(s)`：看起来像小数的字符串 → 浮点数

```python
age = 18
print("年龄是" + str(age))   # 数字 → 字符串，再拼接

age_text = "18"
age_number = int(age_text)   # 字符串 → 整数，再计算
print(age_number + 1)        # 19
```

> **踩坑**
>
> `int("18.5")` 会 `ValueError`——带小数点要用 `float()`。 `int("hello")` 也会 `ValueError`——内容根本不是数字。 用户输入不可信，后面第 8 课会用 `try/except` 优雅处理；现在先知道「转失败会报错」。

## f-string：现在写 Python 最顺手的拼串方式

在字符串前加 `f`，花括号里写变量或表达式，Python 会把值嵌进去。 比一堆 `+` 和 `str()` 可读得多，也是日常代码里的默认选择。

```python
name = "hulei"
age = 18
print(f"我叫{name}，今年{age}岁")
print(f"明年 {age + 1} 岁")   # 花括号里可以写表达式
```

> **原理**
>
> f-string 在运行时求值花括号里的表达式，再转成字符串嵌进去。 所以 `f"{age + 1}"` 会先算加法，再显示——类型对了，表达式随便写。

第一课预告过 `"你好，" + name` 要求两边都是字符串； f-string 里数字可以直接写进 `{age}`，不必手动 `str()`。 两种写法都对，新代码优先 f-string。

## `input()`：程序第一次「听你说」

`input("提示语")` 会暂停程序，在终端显示提示，等你打字并按回车。 你输入的内容，作为**字符串**返回给程序。

```python
user_name = input("请输入你的名字：")
print(f"你好，{user_name}")
print(type(user_name))   # <class 'str'>
```

> **原理**
>
> **无论你敲的是 18 还是 hello，`input()` 返回的永远是 `str`。** 这是整课最重要的记忆点之一。 看起来像数字 ≠ 是数字；要参与运算，必须 `int()` 或 `float()`。

> **踩坑**
>
> `age = input("年龄：")` 之后写 `age + 1` 会 `TypeError`—— 你在给字符串做加法，不是给整数。 正确顺序：先 `input`，再 `int(...)`，再计算。

## 把输入和函数接起来

第一课学的函数，在这一课开始真正干活：读入 → 转换 → 交给函数 → 输出。

```python
def next_year(current_age: int) -> int:
    return current_age + 1

age_text = input("请输入你的年龄：")
age_number = int(age_text)
print(f"明年你 {next_year(age_number)} 岁")
```

注意数据流：`input` 产出字符串 → `int` 产出整数 → `next_year` 接收整数、返回整数 → f-string 负责展示。 每一步类型清晰，程序就不容易乱。

> **原理**
>
> 类型标注（如 `current_age: int`）在这里特别有用： 它提醒读者「这个函数期望整数，别传字符串进来」。 运行时 Python 仍不会自动帮你检查，但你自己会在调用前做好 `int()` 转换。

## 一条完整的小练习思路

配课文件里的练习可以概括成四步：

2. `input` 读一个「数字」（其实是字符串）
4. 写 `double(n: int) -> int`，返回两倍
6. `int(...)` 把输入转成整数
8. 用 f-string 打印：你输入的是 X，两倍是 Y

```python
my_num = input("请输入一个数字：")
my_num_int = int(my_num)

def double(n: int) -> int:
    return n * 2

print(f"你输入的数字是 {my_num}，两倍是 {double(my_num_int)}")
```

这里 `my_num` 和 `my_num_int` 可以同名覆盖（`my_num = int(my_num)`）， 但分开两个名字，调试时更容易看清「转换前 / 转换后」——初学阶段这样写更清楚。

## 建议你自己练的几件事

2. 用 `+` 和 f-string 各写一遍同一句自我介绍，体会可读性差别。
4. `input` 读年龄，分别用 `int` 和 `float` 转换，试试输入 `18.5` 时谁成功、谁报错。
6. 写 `greet(name: str) -> str`，返回 `f"你好，{name}"`，再和 `input` 联用。
8. 故意对 `input` 的结果不算 `int` 就传给需要整数的函数，观察 `TypeError` 报什么。

## 收束

这一课的核心就一句：**外界进来的数据，先当字符串；要算数，显式转；要展示，f-string 最省心。** 下一课进入 `if / else`——程序可以根据条件走不同分支， 比如「年龄是否成年」「输入是否为空」。判断逻辑，是写交互程序的真正起点。
